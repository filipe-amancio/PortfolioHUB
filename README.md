SOBRE O PROJETO:

Este portfólio foi criado como parte do Desafio de Entrega Intermediária da disciplina de
Desenvolvimento Web no UniCEUB. O objetivo é reunir projetos acadêmicos e pessoais
em um perfil profissional público, aplicando boas práticas de versionamento com Git e GitHub.
