## Destaques

- Layout limpo e responsivo (desktop, tablet e celular), com menu mobile
- Tema claro/escuro automático, com botão para alternar (preferência salva no navegador)
- Acessível: HTML semântico, foco visível, navegação por teclado, link "pular para o conteúdo" e respeito a `prefers-reduced-motion`
- SEO e prévia de compartilhamento (meta description e Open Graph para LinkedIn/WhatsApp)
- Sem frameworks nem dependências: HTML, CSS e JavaScript puros; foto otimizada (~100 KB)

## Estrutura

```
PortfolioHUB/
├── index.html              # Página principal
├── assets/
│   ├── css/style.css       # Design tokens, layout e componentes
│   ├── js/script.js        # Tema, menu mobile, animações e "copiar e-mail"
│   └── images/             # Foto e favicon
├── .gitignore
└── README.md
```

## Executar localmente

```bash
git clone https://github.com/filipe-amancio/PortfolioHUB.git
cd PortfolioHUB
# Abra o index.html no navegador ou use a extensão Live Server do VS Code
```
